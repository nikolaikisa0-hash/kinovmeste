# КиноВместе

Сайт для совместного просмотра фильмов. Каталог берётся из Internet Archive
(коллекция `feature_films`): это около 28 тысяч полнометражных фильмов в
общественном достоянии, их можно смотреть бесплатно и законно.

## Запуск

```bash
python3 server.py
```

Откройте http://localhost:8000. Порт можно сменить переменной окружения `PORT`.
Зависимостей нет, нужен только Python 3.8+.

## Как пользоваться

1. Выберите фильм и нажмите «Смотреть вместе», либо «Создать комнату».
2. Нажмите «🔗 Пригласить» и отправьте ссылку друзьям.
3. Пуск, пауза и перемотка синхронизируются у всех; есть чат.

Ещё:

- Подборки «Советское кино» и «Мультфильмы» (классика 1900–1960-х).
- Субтитры: если у фильма они есть на archive.org, включаются кнопкой CC в плеере
  (чаще всего это автоматические английские).
- Эмодзи-реакции поверх видео — видны всем в комнате.
- Имя можно сменить, нажав на него в боковой панели.

## Источники фильмов

- **Классика · Internet Archive** — ~28 000 фильмов в общественном достоянии, жанры,
  советское кино, мультфильмы. Поиск понимает русские названия
  («Ночь живых мертвецов» → Night of the Living Dead) через Википедию.
- **По ссылке: VK Видео, Rutube, YouTube** — вставьте ссылку на видео (или код встраивания из VK), и вся комната смотрит его синхронно.
- **Новые фильмы · YouTube** — фильмы, которые студии и правообладатели сами бесплатно
  выкладывают на YouTube (Мосфильм, Ленфильм, официальные каналы и т.д.).
  Поиск требует ключ `YOUTUBE_API_KEY`; без него можно вставить ссылку на видео.

### Как получить YOUTUBE_API_KEY (бесплатно, ~5 минут)

1. https://console.cloud.google.com → создайте проект.
2. «APIs & Services» → «Library» → включите **YouTube Data API v3**.
3. «Credentials» → «Create credentials» → «API key» → скопируйте ключ.
4. Локально: `YOUTUBE_API_KEY=ваш_ключ python3 server.py`; на Render — вставьте
   в поле `YOUTUBE_API_KEY`. Бесплатного лимита хватает примерно на 100 поисков в день
   (повторные запросы берутся из кэша).

## Публикация в интернете (Cloudflare, бесплатно и без карты)

Для Cloudflare есть отдельная версия сервера на JavaScript: `worker/index.js`
(Worker + Durable Object на каждую комнату), настройки — в `wrangler.jsonc`.
Страница сайта (`static/index.html`) общая для обеих версий.

1. Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (только почта).
2. **Workers & Pages** → **Create** → **Import a repository** → подключите GitHub
   и выберите репозиторий `kinovmeste`.
3. Оставьте настройки по умолчанию (команда деплоя `npx wrangler deploy`) → **Deploy**.
4. Сайт появится на адресе вида `https://kinovmeste.ВАШ-ПОДДОМЕН.workers.dev`.
5. Ключ YouTube (по желанию): Worker → **Settings** → **Variables and Secrets** →
   **Add** → тип **Secret**, имя `YOUTUBE_API_KEY`.

Дальше Cloudflare сам пересобирает сайт после каждого `git push` в `main`.

## Панель администратора сайта

Страница `/admin` показывает открытые комнаты: кто внутри, кто администратор, что смотрят,
идёт ли фильм и на какой минуте, а также оценку «комнато-часов» за сутки (бесплатный
Cloudflare даёт примерно 28 часов работы комнат в день).

Чтобы включить, задайте пароль: Worker → **Settings** → **Variables and Secrets** → **Add** →
тип **Secret**, имя `ADMIN_PASSWORD` → **Deploy**. Локально: `ADMIN_PASSWORD=пароль python3 server.py`.

## Возврат в комнату

Сайт помнит последние комнаты: на главной есть блок «Вернуться в комнату», а если вкладку
закрыли посреди фильма — появится предложение продолжить. Имя и корона администратора 👑
сохраняются, переподключение не пишет в чат «вышел/зашёл».

В Cloudflare-версии комнаты работают через WebSocket и «спят» между событиями, чтобы не тратить
бесплатный лимит; Python-версия использует Server-Sent Events — страница сама выбирает, что доступно.

Локальная проверка Cloudflare-версии: `npx wrangler dev` (нужен Node.js).

## Временная ссылка без хостинга

Пока компьютер включён и сайт запущен:

```bash
ssh -o ServerAliveInterval=30 -R 80:localhost:8000 nokey@localhost.run
```
