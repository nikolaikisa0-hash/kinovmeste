# КиноВместе

Сайт для совместного просмотра фильмов. Каталог берётся из Internet Archive
(коллекция `feature_films`): это около 28 тысяч полнометражных фильмов в
общественном достоянии, их можно смотреть бесплатно и законно.

## Запуск

```bash
python3 server.py
```

Откройте http://localhost:8000. Порт можно сменить переменной окружения `PORT`.
Зависимостей нет, нужен только Python 3.8+.

## Как пользоваться

1. Выберите фильм и нажмите «Смотреть вместе», либо «Создать комнату».
2. Нажмите «🔗 Пригласить» и отправьте ссылку друзьям.
3. Пуск, пауза и перемотка синхронизируются у всех; есть чат.

Ещё:

- Подборки «Советское кино» и «Мультфильмы» (классика 1900–1960-х).
- Субтитры: если у фильма они есть на archive.org, включаются кнопкой CC в плеере
  (чаще всего это автоматические английские).
- Эмодзи-реакции поверх видео — видны всем в комнате.
- Имя можно сменить, нажав на него в боковой панели.

## Источники фильмов

- **Классика · Internet Archive** — ~28 000 фильмов в общественном достоянии, жанры,
  советское кино, мультфильмы. Поиск понимает русские названия
  («Ночь живых мертвецов» → Night of the Living Dead) через Википедию.
- **Новые фильмы · YouTube** — фильмы, которые студии и правообладатели сами бесплатно
  выкладывают на YouTube (Мосфильм, Ленфильм, официальные каналы и т.д.).
  Поиск требует ключ `YOUTUBE_API_KEY`; без него можно вставить ссылку на видео.

### Как получить YOUTUBE_API_KEY (бесплатно, ~5 минут)

1. https://console.cloud.google.com → создайте проект.
2. «APIs & Services» → «Library» → включите **YouTube Data API v3**.
3. «Credentials» → «Create credentials» → «API key» → скопируйте ключ.
4. Локально: `YOUTUBE_API_KEY=ваш_ключ python3 server.py`; на Render — вставьте
   в поле `YOUTUBE_API_KEY`. Бесплатного лимита хватает примерно на 100 поисков в день
   (повторные запросы берутся из кэша).

## Публикация в интернете (Render, бесплатно)

1. Создайте аккаунт на https://github.com и новый репозиторий (например `kinovmeste`).
2. Загрузите код. Локальный git-репозиторий уже готов:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/kinovmeste.git
   git push -u origin main
   ```
3. Войдите на https://render.com через GitHub → «New» → «Blueprint» →
   выберите репозиторий. Render прочитает `render.yaml`, спросит `YOUTUBE_API_KEY`.
4. Через пару минут сайт будет на адресе вида `https://kinovmeste.onrender.com` —
   эту ссылку можно отправлять друзьям в любом городе.

На бесплатном плане сервер засыпает без посетителей и просыпается ~30 секунд.
Комнаты и чат хранятся в памяти и очищаются при перезапуске.

## Временная ссылка без хостинга

Пока компьютер включён и сайт запущен:

```bash
ssh -o ServerAliveInterval=30 -R 80:localhost:8000 nokey@localhost.run
```
